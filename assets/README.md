# OX-DX Assets

This directory contains the canonical OX-DX visual asset system.

- Master logo: `brand/logo/ox-dx-logo-primary.svg`
- Master icon: `brand/icon/ox-dx-icon.svg`
- Wordmark: `brand/wordmark/ox-dx-wordmark.svg`
- Lockups: `brand/lockups/`
- Web hero/header/footer/social: `web/`
- GitHub and README graphics: `documentation/github/` and `documentation/README/`
- Supporting vector language: `vector/`
- Editable/source references: `source/`

Future contributors should derive new assets from the canonical geometry and documented tokens. Do not redraw the symbol, modify the wordmark, invent palette values, or embed new technical ontology semantics in decorative graphics.
