## 100-word description

**OX-DX is a Universal Ontology & Experience Engine for describing heterogeneous evidence without forcing native systems into one artificial shape. Its Universal Ontology provides a canonical vocabulary, while a typed graph keeps containment, projection, observation, and representation distinct. The current Rust implementation discovers software structure and syntax evidence, preserves provenance, and uses deterministic identities and relations. The ontology spans from UNIVERSE to BIT as a resolution spine, not a mandatory hierarchy. Later semantic, runtime, representation, and low-level capabilities remain gated or planned. OX-DX communicates the rule it engineers: observe first, state boundaries, preserve the trace, and resolve only what evidence supports.**
