# OX-DX Final Brand Checklist

Use before publishing any OX-DX material.

## IDENTITY

- [ ] Brand is **OX-DX**.
- [ ] Descriptor is **Universal Ontology & Experience Engine**.
- [ ] Technical engine is **Universal Ontology Engine** when implementation is meant.
- [ ] Repository remains `universal-ontology-engine` when repository identity is meant.
- [ ] No layer names are used as arbitrary synonyms.

## VOICE

- [ ] Clear.
- [ ] Intelligent.
- [ ] Direct.
- [ ] Philosophically grounded.
- [ ] No hype.
- [ ] Poetic lines point to real concepts.
- [ ] Uncertainty is not hidden by language.

## QURANIC BOUNDARY

- [ ] Inspiration remains philosophical.
- [ ] No fabricated scripture.
- [ ] No invented Arabic.
- [ ] No divine authority claim.
- [ ] No claim that 49 levels are Quranic doctrine.
- [ ] Religion is not used as engineering proof.

## VISUAL

- [ ] Approved master logo/variant used.
- [ ] Master logo geometry not recreated or modified.
- [ ] Interrupted Evidence Field grammar used for new supporting work.
- [ ] Canonical palette used.
- [ ] Canonical typography used.
- [ ] 7 / 21 / 49 supporting proportions used where applicable.
- [ ] Grunge is controlled: **CLEAN STRUCTURE. DIRTY SURFACE.**
- [ ] Negative space is intentional.
- [ ] Meaning survives monochrome.
- [ ] Texture does not damage critical information.

## ACCESSIBILITY

- [ ] Text contrast is sufficient.
- [ ] Critical meaning is not color-only.
- [ ] Focus remains visible.
- [ ] Reduced-motion behavior exists.
- [ ] Diagram works without hover/animation.
- [ ] Compact layout removes context before destroying legibility.

## TECHNICAL

- [ ] Claims are supported.
- [ ] Current implementation status is accurate.
- [ ] Planned work is not presented as implemented.
- [ ] Canonical terminology is correct.
- [ ] Ontology/specification is untouched by brand interpretation.
- [ ] Evidence, provenance, identity, projection, observation, and containment remain distinct.

## COPY

- [ ] Existing canonical phrase used before inventing a new one.
- [ ] One major headline per composition.
- [ ] Social/release copy is not more certain than technical documentation.
- [ ] No fake benchmark, fake science, or fake authority.

## GOVERNANCE

- [ ] Asset status is correct: CANONICAL / APPROVED / EXPERIMENTAL / DEPRECATED.
- [ ] New canonical changes have explicit approval.
- [ ] Replacement/deprecation path is documented.
- [ ] Brand version impact was considered.

## FINAL FOUR

- [ ] What was observed is clear.
- [ ] What was inferred is clear.
- [ ] What is implemented is clear.
- [ ] What remains unknown/planned is clear.
