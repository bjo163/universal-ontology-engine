# About OX-DX

## Who OX-DX is

OX-DX is the public brand and system identity for the **Universal Ontology & Experience Engine**.

Its technical implementation is the **Universal Ontology Engine**, a Rust workspace in this repository.

## What it is building

OX-DX is building an evidence-first way to describe heterogeneous systems with a common ontology and typed graph while preserving native structure, provenance, identity boundaries, and explicit relation classes.

The Universal Ontology defines 49 canonical types from `UNIVERSE` to `BIT` as a resolution spine over a graph.

## Why it exists

Different systems expose different structures. A crate, package, module, source construct, runtime event, and encoded representation are not the same thing.

Forcing them into one convenient tree can erase the distinctions that made the evidence useful.

OX-DX exists to make those distinctions explicit.

## What it does today

At the current hardened scope, the Rust engine provides:

- canonical ontology registry validation;
- core ontology types and stable IDs;
- typed graph relations and invariants;
- read-only filesystem/Git discovery;
- Rust syntax/AST observation;
- deterministic syntax observation for TypeScript, JavaScript, Python, Go, Java, and Kotlin;
- repository self-inspection;
- CLI surfaces for validation, inspection, discovery, parsing, and self inspection.

## What it deliberately does not claim

OX-DX is not currently:

- a universal compiler;
- a mandatory 49-folder hierarchy;
- a source-rewriting engine;
- an absolute truth engine;
- a complete semantic-understanding system;
- a complete runtime-observation platform;
- a finished binary/bit analysis engine;
- theological doctrine.

Later capabilities remain gated or planned according to repository status.

## The rule

**EVIDENCE FIRST.**

Do not force the shape.

Preserve the trace.

Connect the relation.

Resolve what can be resolved.
