# OX-DX Copy Patterns

These patterns are reusable structures for README, documentation, releases, social posts, GitHub, and future website copy. They do not override `messaging-framework.md` or `terminology.md`.

## Pattern A — Observation → Question → Technical answer

**Observation:** Systems expose different native structures.

**Question:** How do we compare them without pretending they are the same?

**Technical answer:** Preserve native evidence, map justified classifications to canonical types, and connect explicit relations in the typed graph.

Use for explainers and introductions.

## Pattern B — Not X. Y.

**Not replacement. Projection.**

Follow immediately with the distinction that makes the contrast true.

Use for memorable conceptual boundaries.

## Pattern C — Philosophical line → technical explanation

**Reality leaves traces.**

Repository layout, manifests, syntax, source spans, graph edges, and later runtime evidence are different observable traces. OX-DX treats them according to their evidence class.

Use for README sections, talks, and selected social copy.

## Pattern D — Problem → OX-DX principle → implementation

**Problem:** Generic directory names can look semantically meaningful.

**Principle:** EVIDENCE FIRST.

**Implementation:** Discovery does not manufacture `UNIT` or `MODULE` solely from a generic `src/` directory.

Use for technical documentation and issue context.

## Pattern E — Big idea → boundary → actual capability

**Big idea:** FROM UNIVERSE TO BIT.

**Boundary:** The 49 levels are a resolution spine over a graph, not 49 mandatory nested containers.

**Actual capability:** The current engine validates the vocabulary and works with structural/syntax evidence; deeper representation readers remain planned.

Use whenever a brand-scale statement could otherwise be mistaken for current implementation.

## Pattern F — What changed → why → proof → remainder

Use for releases and milestone communication:

1. What changed.
2. Why it matters.
3. What is now verified.
4. What remains gated or planned.
