# OX-DX Gen-Z Communication Style

Gen-Z in OX-DX means **clear, fast, confident, and unbloated**.

It does not mean childish copy, forced slang, memes, or pretending technical work is entertainment.

## Rules

- Prefer short sentences.
- Prefer short paragraphs.
- Lead with strong verbs.
- Use clear contrasts.
- Remove filler before removing necessary precision.
- Explain jargon once, then use it consistently.
- Use visual rhythm: statement, space, explanation.
- Let one sharp line carry the attitude; let the next line carry the technical truth.

## Approved rhythm

**Systems are messy.**

A model should preserve the evidence that made them messy before projecting a cleaner view.

**Don't flatten the world.**

The graph can express relations without converting every connection into structural ownership.

**Native structure stays native.**

Canonical types provide interoperability vocabulary around source evidence; they do not replace native language semantics.

## Do not

- force `bro`, `lol`, `vibe`, or meme language into technical communication;
- overuse one-line fragments until documentation becomes vague;
- substitute attitude for evidence;
- treat lowercase/unstyled copy as automatically “young”;
- use exclamation marks to manufacture energy.

## Test

If a sentence sounds like marketing wrote it after reading three trend reports, rewrite it.

If it sounds like a strong engineer explaining a difficult distinction in plain language, keep it.
