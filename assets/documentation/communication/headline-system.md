# OX-DX Headline System

OX-DX uses a small canonical phrase set. Do not create a new slogan when one of these already carries the message.

| Role | Canonical headline | Use |
|---|---|---|
| PRIMARY | **FROM STRUCTURE TO EXPERIENCE.** | Main brand direction; hero, README opening, major public surfaces. |
| SECONDARY | **FROM UNIVERSE TO BIT.** | Resolution span; ontology and architecture communication. |
| PRINCIPLE | **EVIDENCE FIRST.** | Engineering discipline, validation, technical explanation. |
| ATTITUDE | **DON'T FORCE THE SHAPE.** | Anti-artificial-structure message. |
| METHOD | **OBSERVE. RESOLVE. UNDERSTAND.** | Explanatory flow and selected product communication. |

## Supporting headline construction

When another headline is genuinely necessary, build it from one of three forms:

- **Direct observation:** “Systems leave traces.”
- **Boundary:** “Observation is not ownership.”
- **Consequence:** “Native structure stays native.”

Keep it short enough to remember and precise enough to defend.

## Rules

- One major headline per composition.
- Do not stack all canonical lines together.
- Uppercase is reserved for canonical statements and compact technical labels.
- Headline energy never overrides status truth.
- A campaign line must not become a new product name or ontology term.

For the approved phrase list, use `canonical-phrases.md`.
