# OX-DX Headline System

Canonical phrase content lives in:

`../brand-bible/canonical-copy.md`

This file governs **headline behavior**, not a second phrase library.

## Roles

- PRIMARY — main brand direction.
- SECONDARY — resolution scale.
- PRINCIPLE — engineering discipline.
- ATTITUDE — boundary / anti-artificial-structure message.
- METHOD — explanatory flow.
- SUPPORTING — contextual, never a replacement for primary identity.

## Rules

- One major headline per composition.
- Uppercase is reserved for canonical short statements and compact technical labels.
- A poetic line must point to a real concept.
- Headline energy never overrides technical status.
- A campaign line never becomes a product name, ontology term, or proof.
