# OX-DX Message Consistency Matrix

| Surface | Primary Message | Secondary Message | Tone | Maximum Length | Required Terms | Forbidden Claims |
|---|---|---|---|---|---|---|
| README | What OX-DX is and why evidence-first resolution exists | Current implementation boundary | Clear + deep | Progressive; opening ≤ 3 short paragraphs | OX-DX, evidence, ontology, graph | Planned work presented as current; absolute truth |
| GitHub description | Shared ontology + typed graph for heterogeneous evidence | Evidence-first | Direct | ~160 characters | ontology, evidence | “fully universal”, generic AI claims |
| Website | FROM STRUCTURE TO EXPERIENCE. | FROM UNIVERSE TO BIT. + current capability boundary | Editorial + precise | Hero ≤ 30 words before detail | OX-DX, evidence | Experience described as fully implemented |
| Documentation | Concept → distinction → example → implementation → reference | Source-of-truth links | Technical | As needed; progressive disclosure | canonical terms | Unreferenced technical invention |
| Issue | Problem and evidence | Scope, acceptance, verification | Operational | Enough to reproduce/decide | evidence, acceptance criteria | Emotional/vague completion claims |
| PR | Change and reason | Impact, validation, remainder | Factual | Concise but complete | validation | Diff-external capability claims |
| Release | What changed | Why, verified scope, what remains | Calm + confident | Scannable sections | verified/status terms | Hype-driven maturity claims |
| Social | One defensible idea | Link to evidence/context | Sharp + restrained | Prefer ≤ 280 chars for short posts | OX-DX or canonical phrase | Universal/absolute claims without boundary |
| CLI | Result of operation | Specific failure/boundary | Factual + script-friendly | Short lines / structured JSON | exact operation/status | Marketing copy, fake progress |
| Future UI | Current state/action | Evidence or next valid action | Calm + direct | Microcopy length | inspect/observe/resolve as appropriate | “magic”, vague empty/error states |

## Rule

The surface changes the length, not the truth.

A social post may be shorter than a specification. It may not be more certain.
