# OX-DX One-Liners and Short Pitches

All variants preserve the same meaning at different lengths. Do not turn them into unrelated campaign slogans.

## Canonical one-liner

**OX-DX is a Universal Ontology & Experience Engine that resolves heterogeneous evidence through a canonical ontology and typed graph without forcing native systems into one artificial shape.**

## Surface variants

### GitHub description

**Universal ontology + typed graph for evidence-first resolution across heterogeneous software systems.**

### README intro

**OX-DX gives heterogeneous evidence a shared ontology and typed graph while preserving native structure, provenance, and explicit relations.**

### Website hero

**Resolve the evidence. Keep the structure. Connect the graph.**

Use with the canonical primary tagline, not as a replacement for it.

### Social bio

**Evidence-first ontology and graph systems. Native structure stays native. FROM UNIVERSE TO BIT.**

### Release footer

**OX-DX — evidence first. State what changed. State what remains.**

### Documentation footer

**The ontology names. The graph connects. The evidence decides what can be claimed.**

## Exact-length short pitches

Word counts use whitespace/punctuation-normalized token counting and treat hyphenated forms such as `OX-DX` and `evidence-driven` as one word.

### 10 words

**OX-DX resolves heterogeneous evidence through ontology, graphs, provenance, and resolution.**

### 20 words

**OX-DX maps heterogeneous evidence into a canonical ontology and typed graph, preserving provenance while resolving structure toward finer representations safely.**

### 50 words

**OX-DX is a Universal Ontology & Experience Engine for describing heterogeneous evidence with a canonical vocabulary and typed graph. It preserves native structure, provenance, and explicit relationships while supporting evidence-driven projection across conceptual and representational scales. The current Rust engine focuses on observable software evidence and deterministic discovery across supported languages.**

### 100 words

**OX-DX is a Universal Ontology & Experience Engine for describing heterogeneous evidence without forcing native systems into one artificial shape. Its Universal Ontology provides a canonical vocabulary, while a typed graph keeps containment, projection, observation, and representation distinct. The current Rust implementation discovers software structure and syntax evidence, preserves provenance, and uses deterministic identities and relations. The ontology spans from UNIVERSE to BIT as a resolution spine, not a mandatory hierarchy. Later semantic, runtime, representation, and low-level capabilities remain gated or planned. OX-DX communicates the rule it engineers: observe first, state boundaries, preserve the trace, and resolve only what evidence supports.**
