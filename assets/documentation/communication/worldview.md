# OX-DX Worldview

OX-DX begins with a simple constraint:

**systems leave traces.**

A directory exists. A manifest declares something. A source construct has a name and span. A relation connects two resources. A runtime event may later show that something happened. Each of these is evidence of a different kind.

The communication worldview follows this progression:

```text
SEE
  ↓
OBSERVE
  ↓
DESCRIBE
  ↓
CONNECT
  ↓
RESOLVE
  ↓
EXPERIENCE
```

This is a communication model, not a claim that the engine implements one mandatory algorithm with these six stages.

## SEE

Begin with what is present. Do not start from the shape we wish the system had.

## OBSERVE

Record what the source, repository, syntax, graph, or runtime evidence actually exposes. Observation creates evidence; it does not create ownership.

## DESCRIBE

Use a stable vocabulary to state what the evidence supports. In OX-DX, the Universal Ontology provides the canonical type vocabulary. Native language and repository structures remain authoritative about their own semantics.

## CONNECT

Relationships belong in a typed graph. Containment is only one relation. Projection, representation, reference, dependency, causation, invocation, and observation must not be collapsed into parent/child ownership.

## RESOLVE

Resolution means moving across increasingly specific conceptual or representational scales while preserving relevant distinctions, identity, and provenance.

## EXPERIENCE

Experience is the broader brand horizon: structured evidence becomes interpretable and useful to people or systems. It is not currently a canonical ontology level and must not be described as a fully implemented subsystem unless repository evidence establishes one.

## What OX-DX refuses to pretend

OX-DX does not communicate as if evidence were absolute truth. It does not treat a path as identity, an observation as ownership, a representation as meaning, or the 49 canonical levels as 49 mandatory physical boxes.

**EVIDENCE FIRST.**

State what was observed. State what was inferred. State what is implemented. State what remains unknown.
