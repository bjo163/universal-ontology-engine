# OX-DX Empty States

An empty state should explain what was inspected and what remains unresolved.

Do not stop at:

> No data.

## Required questions

An empty state should answer as many as are relevant:
- what scope was inspected?
- what evidence was found?
- what evidence was not found?
- is this unknown, unsupported, filtered out, or genuinely empty?
- what safe next inspection action exists?

## Canonical patterns

> No native evidence supports this classification.

> No relationship has been observed in the current scope.

> No representation has been resolved at this depth.

> No supported evidence was found for this query.

> This level is currently unmaterialized for the selected object.

## Filtered empty

Say when filters caused the state:

> No relations match the active filter.

Do not imply no relation exists globally.

## Planned capability

If an empty state depends on an unimplemented feature:

> This evidence surface is not available at the current implementation scope.

Do not fabricate placeholder evidence to make the UI look complete.

## Actions

Possible:
- Clear Filter
- Broaden Scope
- View Source
- Inspect Parent Context
- Return to Graph

Only show valid actions.
