# OX-DX Evidence Viewer

The Evidence Viewer is a future inspection surface for source/native evidence and its interpreted relationships.

## Purpose

Show:
- source;
- native structure;
- observed evidence;
- classification;
- provenance;
- relationships.

Source evidence must remain visually distinguishable from interpretation.

## Suggested regions

### SOURCE
Native text, structure, manifest data, syntax observation, event data, or representation evidence.

### OBSERVATION
What the system actually observed.

### CLASSIFICATION / PROJECTION
What canonical TYPE, KIND, or projection is supported.

### RELATIONSHIPS
Typed graph edges connected to the evidence.

### PROVENANCE
Where and how the evidence was obtained.

## Visual rule

Evidence is primary.

Interpretation is displaced from it using a witness bracket, separate rail, offset frame, or explicit label.

Do not restyle source material until it looks like the canonical ontology.

## Evidence states

Where supported, distinguish raw/native, classified, projected, observed, and unresolved evidence.

Unknown or unsupported classification remains unresolved rather than being filled by heuristic certainty.

## Actions

Possible future actions:
- Inspect
- Trace
- Compare
- View Source
- View Relation
- Resolve
- Verify

Actions must reflect real capability.

## Empty copy

Preferred:
> No native evidence supports this classification.

Preferred:
> Projection is not established from the current evidence.

Do not fabricate evidence.
