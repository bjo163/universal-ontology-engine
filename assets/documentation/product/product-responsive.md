# OX-DX Responsive Product System

Do not shrink desktop.

Resolve context according to available space.

Canonical product principle:

**MORE SPACE → MORE CONTEXT**

**LESS SPACE → MORE FOCUS**

This adapts the visual responsive grammar to product use.

## Mobile

Prioritize:
- current object;
- essential evidence;
- current relation/status;
- recoverable context.

Move secondary context into sheets, drawers, stacked regions, or explicit inspection steps.

Do not preserve a desktop sidebar simply because it exists.

## Tablet

Support:
- one primary surface;
- one collapsible context/inspection region;
- compact graph neighborhoods;
- contextual resolution controls.

## Desktop

Allow:
- primary inspection field;
- secondary evidence/relations;
- inspection rail;
- richer provenance;
- more graph context.

## Large screen

Use extra space for:
- comparison;
- relationship neighborhoods;
- source + interpretation side-by-side;
- provenance;
- contextual history.

Do not use extra space only to make type enormous.

## Responsive priority

When space decreases:
1. remove decorative disturbance;
2. remove secondary annotation;
3. collapse duplicate relation rails;
4. move provenance/detail off the primary plane;
5. preserve target, essential relation, status, and focus.

## Navigation

Sidebars may become:
- scope strip;
- modal;
- sheet;
- context selector;
- history view.

Responsive layout follows task, not component-library habit.
