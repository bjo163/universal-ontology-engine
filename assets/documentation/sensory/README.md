## Core philosophy

**EFFECTS MUST COMMUNICATE SYSTEM BEHAVIOR.**

Conceptual sensory model:

`NOISE → SIGNAL → STRUCTURE → RESOLUTION`

This is not an engine pipeline.

OX-DX sensory behavior should let a person feel:
- something is being observed;
- something is being traced;
- something is resolving;
- something remains unknown;
- something changed;
- something was verified;
- nothing needs to happen.
