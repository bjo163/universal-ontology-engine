# OX-DX Ambient System

Ambient sound is optional.

Routine product interfaces should not require it.

Potential contexts:
- brand film;
- interactive explorer;
- physical installation;
- presentation/demo;
- optional website experience with explicit user initiation.

## Character

**a system quietly existing**

Qualities:
- minimal;
- deep;
- slow;
- textural;
- non-invasive;
- non-melodramatic.

## Material

Use:
- low stable room-like resonance;
- sparse mechanical/organic texture;
- very slow density change;
- occasional subtle grain;
- large silence intervals.

Avoid:
- meditation pads;
- generic ambient synth beds;
- horror drones;
- trailer braams;
- constant pulse;
- obvious “computer room” loops.

## Structure

Ambient is not a song.

Prefer:
- evolving field;
- irregular long pauses;
- low event density;
- no obvious loop point.

## Interaction

Ambient never confirms actions.

UI sounds must remain intelligible if ambient is enabled.

## Accessibility / control

Ambient:
- off by default in product UI;
- user initiated where practical;
- separately mutable from UI SFX;
- disabled in Silent mode;
- never required for meaning.
