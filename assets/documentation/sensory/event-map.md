# OX-DX Multi-Sensory Event Map

This is the master sensory event vocabulary.

| Event | Visual | Sound | Motion | Text | Intensity | Silence option |
|---|---|---|---|---|---:|---|
| DISCOVER | new evidence carrier + witness | Grain + Breath + faint Rail | evidence enters from valid anchor | DISCOVERED / source label when useful | 2 | yes for background discovery |
| INSPECT | focus witness + local trace | short Witness | bracket/trace reveal | INSPECT / object label | 1–2 | yes |
| OBSERVE | offset witness frame; target unchanged | soft Witness + Breath | non-invasive witness reveal | OBSERVED only if technically supported | 1 | yes |
| TRACE | provenance/relation rail gains persistence | Grain → Breath → faint Rail | source-to-target trace | TRACE / relation label | 2 | yes |
| CONNECT | supported relation rail appears | paired Rail settles | relation continuity builds | exact relation name | 2 | yes |
| RESOLVE | fragmented carriers become clearer while gaps remain honest | Settle | persistence/detail increases around invariant | RESOLVED only when product semantics support it | 2–3 | yes |
| VERIFY | local geometry stabilizes + small confirmation cut | short Settle + Witness | irregularity settles | VERIFIED + scope | 2 | optional |
| UNKNOWN | open boundary / void / incomplete trace | none | none or minimal settle | UNKNOWN / unresolved explanation | 0–1 | **default** |
| WARNING | bounded interruption + explicit label | restrained interrupted Witness | local shift/break | WARNING + cause/action | 2 | yes; text/geometry remain |
| ERROR | local break/offset/signal loss | broken transient + short low resonance | bounded disruption then readable error state | precise failure class | 2–3 | yes; text required |
| SUCCESS | stable local state | optional quiet Settle | minimal | SUCCESS/complete only if useful | 1 | **preferred for routine** |
| LOADING | pending region/persistence cue | none | subtle local progression only if real | DISCOVERING / INSPECTING / etc. | 0–1 | **default** |
| TRANSITION | layer/context separation or convergence | soft transition texture | resolution-derived context change | context title if needed | 2 | yes |

## Rules

1. An event can be visually expressed without sound.
2. An event can be expressed without motion.
3. Text carries the exact state when technical semantics matter.
4. Sound never upgrades certainty.
5. Visual brightness never upgrades certainty.
6. Unknown is not automatically warning.
7. Verification is not generic success.
8. Loading never implies fake progress.

## Intensity gate

Routine interaction:
- Level 0–2.

Major product state:
- Level 3.

Level 4–5:
- major reveal, launch, brand film, presentation, or installation only.

No ordinary click deserves cinematic treatment.

## Cross-sensory consistency questions

For every implementation ask:
- Does the visual effect belong to OX-DX?
- Does the sound use the same event family?
- Does motion reinforce the same meaning?
- Does text state the same condition?
- Is the state understandable without sound?
- Is the state understandable without motion?
- Is the state understandable in high contrast?
