# OX-DX Sonic Logo — SPEC_ONLY v1.0

No audio master is committed in this task.

This file defines the canonical production specification.

## Concept

**fragmented signal → alignment → resolution**

It should feel like:

**a signal becoming a pattern.**

## Total duration

Target: **490 ms**, using the canonical field-duration family.

## Three-part structure

### 0–98 ms — FRAGMENT
- dry grain/textural click;
- very short filtered noise fragment;
- asymmetrical, incomplete.

### 98–294 ms — ALIGN
- second related transient enters;
- two restrained resonant components briefly coexist;
- slight instability/beating may be present;
- no melody.

### 294–490 ms — SETTLE
- noise reduces;
- relation stabilizes into a quiet short dyad/resonance;
- tail ends cleanly rather than blooming cinematically.

## Loudness character

Recognizable at low volume.

Never startling.

Works in mono.

Stereo production may add minimal width, but the identity must survive downmix.

## Avoid

- corporate three-note melody;
- startup chord;
- cinematic boom;
- laser;
- sparkle;
- notification ding;
- bass-drop logo sting.
