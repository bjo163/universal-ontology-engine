# OX-DX Color System

Brand Bible authority:

`../OX-DX-BRAND-BIBLE-v1.0.md`

OX-DX is dark-first and monochrome-capable.

Color is semantic reinforcement, not decoration.

| Role | Token | HEX | Usage |
|---|---|---|---|
| PRIMARY / SURFACE | Void | `#07090A` | Primary dark canvas |
| SECONDARY / SURFACE | Charcoal | `#111418` | Raised dark surface |
| SURFACE / BORDER | Graphite | `#20252B` | Secondary surface, structural border |
| TEXT | White | `#F5F7F8` | Primary text and geometry |
| MUTED / BORDER | Muted Steel | `#99A2AA` | Annotation, secondary border/trace |
| SIGNAL / OBSERVATION | Electric Cyan | `#00D8FF` | Witness anchor, primary technical signal |
| ATTENTION | Acid | `#8CFF00` | Rare active / verified / attention emphasis |
| PROJECTION / SECONDARY ACCENT | Ultraviolet | `#9C4DFF` | Displaced projected/alternate view |
| INVERSE | Black | `#000000` | Monochrome foreground on light fields |

## Uncertainty

Uncertainty is **not a color token by itself**.

Use:
1. structural break / void / lower persistence;
2. Muted Steel annotation when needed.

Never communicate uncertainty only through low contrast.

## Rules

1. Master identity must work in pure black or white.
2. Cyan is the primary technical accent.
3. Acid and Ultraviolet are contextual and restrained.
4. No separate magenta primary token is introduced in Brand Bible v1.0.
5. Do not add a color per TYPE, KIND, state, or edge.
6. Grunge/dirty surface uses deterministic interruption and opacity, not new colors.
7. Critical text prioritizes contrast over atmosphere.
8. Meaning must survive monochrome.
