# OX-DX Typography

The OX-DX wordmark is custom vector geometry and is not a font. Distribution SVGs outline the lettering, so they do not require installed fonts.

- **Primary display:** custom OX-DX chamfered wordmark geometry; use only for the brand name.
- **Secondary/body:** a neutral grotesk or system sans with restrained weights. Recommended web stack: `Inter, ui-sans-serif, system-ui, sans-serif`.
- **Technical/mono:** `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`.
- **Hierarchy:** wordmark > concise uppercase statement > descriptor > technical annotation.

Do not replace the canonical vector wordmark with typed text. Do not commit proprietary font binaries.
