# OX-DX Brand → TUI Traceability

| Brand principle | TUI rule | Visible behavior | User experience |
|---|---|---|---|
| EVIDENCE FIRST | source-first layout | native evidence before classification | “I can inspect what supports this.” |
| DON'T FORCE THE SHAPE | choose list/graph/spine by evidence | no universal tree/card layout | structure stays honest |
| OBSERVATION IS NOT OWNERSHIP | observation offset rail | OBSERVATION separate from target | runtime does not become child |
| PROVENANCE IS NOT IDENTITY | provenance secondary rail | source/path separate from object title | origin stays traceable |
| RESOLUTION, NOT REDUCTION | Resolution Spine | deeper view adds supported detail | “I can go deeper.” |
| THE GRAPH CONNECTS | typed relation topology | exact edge kinds visible | relationships are first-class |
| GRAPH ≠ TREE | parent only for containment | other edges stay neighbors/relations | no false hierarchy |
| UNKNOWN IS VALID | quiet unknown state | open boundary + UNKNOWN | uncertainty is honest |
| NO FALSE CERTAINTY | text-led statuses | observed/verified/unknown distinct | nothing overclaims |
| CLEAN STRUCTURE. DIRTY SURFACE. | partial separators, clean content | controlled interruptions only | raw without mess |
| MOTION IS RESOLUTION | bounded local frames | trace/resolve reveals state | motion explains change |
| SILENCE IS VALID | default silent TUI | no routine beep | quiet concentration |
| Gen-Z clarity | short labels/actions | concise command/help text | fast scanning |
| Intelligent precision | exact TYPE/KIND/edge labels | technical names preserved | trustworthy terminology |
| ORDER INSIDE CHAOS | stable anchor + asymmetric context | one dominant field + rails | complexity remains navigable |
| FROM UNIVERSE TO BIT | 49-level spine | current + broader/finer context | scale is visible |
| FROM STRUCTURE TO EXPERIENCE | inspection instrument | evidence/graph/provenance become navigable | structure becomes usable experience |
| Quranic depth, not authority | restraint/measure, no sacred UI ornament | silence/order/space | reflective without religious claim |

## Rule

Every future TUI pattern should be explainable:

`BRAND → TUI RULE → VISIBLE BEHAVIOR → USER EXPERIENCE`

If not, it is likely generic decoration or requires governance.
