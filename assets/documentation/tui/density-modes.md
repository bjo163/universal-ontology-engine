# OX-DX TUI Density Modes

## LOW

Use for:
- orientation;
- startup;
- conceptual navigation;
- small terminals.

Show:
- current object;
- level;
- one status;
- minimal relations.

## MEDIUM

Default normal use.

Show:
- object;
- primary evidence;
- relation summary;
- provenance summary;
- status.

## HIGH

Technical inspection.

Show:
- dense source;
- relation list;
- metadata;
- graph neighborhood;
- diagnostics.

Reduce decorative separators.

## INSPECTION

Maximum evidence density.

Show:
- raw/source evidence;
- exact spans;
- typed relations;
- provenance;
- representation detail when supported.

Brand decoration is minimal.

## Rule

Density changes information volume and spacing.

It must not hide semantic distinctions.

High density is not “more OX-DX” than low density.
