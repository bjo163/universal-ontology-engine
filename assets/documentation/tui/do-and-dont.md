# OX-DX TUI Do / Don't

## DO

- show evidence;
- show context;
- show current resolution;
- support keyboard-first operation;
- support arrow keys;
- use quiet states;
- preserve provenance;
- separate observation;
- show exact relation names;
- preserve source;
- let unknown remain unknown;
- degrade to ASCII/monochrome;
- keep sound optional;
- keep animation local;
- use one dominant inspection surface.

## DON'T

- simulate hacker movies;
- glow everything;
- animate everything;
- beep everything;
- use ASCII decoration everywhere;
- hide evidence behind interpretation;
- turn unknown into error;
- turn runtime observation into ownership;
- force 49-level nesting;
- call every relation parent/child;
- require vi navigation;
- require mouse;
- require truecolor;
- require Nerd Fonts;
- rebuild a web dashboard inside the terminal;
- claim future TUI vocabulary is already implemented CLI functionality.
