# OX-DX TUI Originality Audit

## Result

**PASS — designed as an original OX-DX terminal instrument and intentionally separated from common terminal-product patterns.**

This is not a claim of global uniqueness.

## Conceptual comparisons

### btop / htop
Do not borrow:
- system-monitor dashboard identity;
- dense meter-first framing;
- permanent resource gauges unrelated to ontology inspection.

OX-DX instead centers evidence, resolution, graph relation, provenance.

### lazygit
Do not borrow:
- Git-specific pane hierarchy as the default architecture;
- action model tied to Git workflows.

OX-DX panes are task/context responsive and may collapse into one dominant inspection field.

### k9s
Do not borrow:
- resource-table/operator-console identity;
- cluster-resource navigation metaphors as universal patterns.

OX-DX uses canonical ontology resolution and typed graph relations.

### Neovim / Helix
Do not borrow:
- editor buffer/mode identity as the product metaphor;
- mandatory modal key culture.

Vi keys are optional aliases.

### ranger
Do not borrow:
- filesystem parent/current/child columns as universal hierarchy.

Parent/child language is reserved for real structural containment.

### Warp
Do not borrow:
- terminal blocks/workflow presentation as core identity.

OX-DX is an inspection instrument, not a shell-history product.

### Starship
Do not borrow:
- prompt-decoration/plugin-segment identity;
- shell telemetry clutter.

OX-DX prompt communicates inspection coordinate only.

## OX-DX signature without logo

Recognizable through:
- Resolution Spine;
- evidence-first hierarchy;
- observation separation;
- provenance rail;
- trace language;
- asymmetric/open framing;
- controlled density;
- quiet unknown;
- exact edge labels;
- terminal-safe witness glyph grammar.

## Generic terminal patterns explicitly rejected

- giant ASCII logos;
- hacker-green default;
- fake hex streams;
- Matrix rain;
- box around everything;
- permanent multi-pane dashboard;
- neon truecolor dependency;
- Nerd Font requirement;
- beep-on-click;
- fake scan line;
- full-screen redraw animation.

## Usability boundary

OX-DX still uses conventional:
- arrow keys;
- Enter/Esc/Tab;
- lists;
- tables;
- scroll;
- standard terminal cursor;
- accessible ANSI conventions.

Originality comes from information relationships, not unfamiliar controls.
