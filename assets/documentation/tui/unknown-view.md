# OX-DX TUI Unknown View

Unknown is not error.

It means current evidence does not establish the requested value/relation/state.

## Canonical expression

Unicode:

```text
UNKNOWN
⋯ continuity not established

evidence   none observed in current scope
next       broaden scope · inspect source
```

ASCII:

```text
UNKNOWN
... continuity not established

evidence   none observed in current scope
next       broaden scope : inspect source
```

## Visual behavior

Use:
- open boundary;
- partial trace;
- deliberate absence;
- reduced density;
- explicit label.

## Do not

- flash;
- use error-red by default;
- use warning siren;
- use giant question mark;
- invent candidate values.

## Sound

Silent by default.

## Motion

None or a short settle into the static unknown state.

## Distinction

`UNKNOWN` = evidence does not establish.

`ERROR` = an operation failed.

`UNMATERIALIZED` = canonical level/object state is specifically known to be absent/unmaterialized.

Do not collapse these.
