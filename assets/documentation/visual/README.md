# OX-DX Visual Language

Master brand authority: `../OX-DX-BRAND-BIBLE-v1.0.md`

This directory remains the canonical specialist source for the supporting visual grammar.

The OX-DX visual system is called the **Interrupted Evidence Field**.

It grows from the approved OX-DX mark: opposed hard-edged structures, a witnessed center, interruption, and resolution. The master logo is locked. This system governs the supporting visual language around it.

## Philosophy

**ORDER INSIDE CHAOS.**

OX-DX does not visualize chaos as randomness. It visualizes the tension between a stable construction and the evidence that interrupts it.

Recurring tensions:
- ORDER × INTERRUPTION
- STRUCTURE × TRACE
- PRECISION × IMPERFECTION
- MACRO × MICRO
- KNOWN × UNRESOLVED
- OBSERVED × INFERRED

## Signature grammar

Recognizable traits:
- open / interrupted frames instead of closed cards;
- off-axis diamond witness anchors instead of circular nodes;
- paired relation rails with changing persistence instead of ordinary arrows;
- deliberate void slots;
- deterministic dirty-surface disturbance instead of random dirt;
- 7 / 21 / 49 spatial logic;
- resolution by decomposition, not zoom;
- monochrome structure with restrained semantic accents.

The graphic vocabulary is:
`LINE · NODE · FRAME · LAYER · VOID · BREAK · TRACE · SIGNAL · DENSITY · FIELD · EDGE · ANCHOR`

These are graphic concepts only, never ontology levels or engine semantics.

## Do / Don't

Do preserve the master logo, use measured interruption, strong voids, deterministic disturbance, color-independent meaning, and accessible contrast.

Do not default to glowing grids, cards, circles, gradients, hexagons, circuit boards, generic AI/Web3 graphics, fake science, or random grunge.

The system is **designed as an original OX-DX visual language and intentionally separated from identified common design patterns.**
