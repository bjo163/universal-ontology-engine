# OX-DX Color Semantics

Color reinforces structure. It does not create meaning by itself.

The approved palette remains unchanged.

| Role | Token | Color | Use |
|---|---|---|---|
| Structure | void / white | #07090A / #F5F7F8 | Primary geometry and readable text |
| Observation | cyan | #00D8FF | Witness anchor / observation emphasis |
| Signal | acid | #8CFF00 | Rare active signal / verified emphasis |
| Projection | ultraviolet | #9C4DFF | Displaced projected/alternate view |
| Uncertainty | muted + break | #99A2AA | Annotation; uncertainty is primarily geometry |
| Surface | charcoal / graphite | #111418 / #20252B | Context depth |

Rules:
1. Monochrome must work.
2. Cyan is primary technical accent.
3. Acid and ultraviolet should not compete in small compositions.
4. Uncertainty is not low contrast alone.
5. Do not create a color per TYPE/KIND/state.
6. No gradient is required for canonical expression.

Observation = cyan **plus** witness anchor.
Projection = ultraviolet **plus** displaced bridge.
Signal = acid **plus** cadence/persistence.
