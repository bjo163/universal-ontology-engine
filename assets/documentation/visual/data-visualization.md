# OX-DX Data Visualization Language

Use OX-DX primitives when they clarify ontology, graph, evidence, provenance, resolution, event, or state relationships. Do not replace a familiar chart when the familiar chart communicates data better.

## Counts — Count Rail
Use segmented persistence along a fixed rail. Label exact counts. Do not imply percentages without a defined scale.

## Levels — Resolution Field
Show ordered positions with visible gaps for unmaterialized levels. Do not nest every level as a box.

## Relations — Persistence Rail
Use paired/segmented rails and anchor geometry. Label technical relation names when semantics matter.

## States — State Cut
Stable field + marked boundary cut + text label. Do not rely only on green/red.

## Events — Event Trace
Witness anchors along a carrier; provenance tails where data exists. Temporal spacing must only represent real time when using a true time scale.

## Provenance — Source Tail
Secondary tail outside identity shape.

## Accessibility
Provide readable labels, textual values when precision matters, color-independent distinction, sufficient contrast, and alt-text guidance in consuming surfaces.
