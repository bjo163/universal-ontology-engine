# OX-DX Evidence Language

Evidence should look discovered. State changes use geometry and persistence, not color alone.

## Raw evidence
Incomplete carriers, measured breaks, no forced classification frame, optional provenance.

## Classified evidence
Add a stable anchor, restrained type label, and field alignment. Do not rebuild the raw object into a different shape.

## Projected evidence
Keep source evidence. Add a displaced secondary geometry connected by an interrupted projection bridge. Projection must not read as containment.

## Observed evidence
Add witness bracket + anchor. The observed object remains unchanged.

## Uncertainty
Prefer structural cues:
- longer void = weaker continuity;
- split anchor = unresolved;
- lower persistence = weaker relation evidence;
- open frame = bounded scope without ownership.

Do not invent confidence percentages.

Priority:
1. identity geometry;
2. observed structure;
3. relations;
4. provenance;
5. annotation;
6. surface disturbance.
