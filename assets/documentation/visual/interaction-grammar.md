# OX-DX Interaction Grammar

Interaction should feel like examining evidence.

## Hover — reveal trace
Reveal one provenance tail, relation rail, or local witness notch. Do not animate the whole field.

## Focus — establish witness
Keyboard focus uses a high-contrast open witness frame while preserving conventional focus visibility.

## Activation — commit anchor
An outline witness may become filled. Avoid mandatory bounce/scale effects.

## Selection — preserve identity
Selection adds witness geometry. Do not recolor the object so heavily that state and identity collapse.

## Drag — carry trace
Moving object remains stable; prior coordinate may leave temporary trace; destination context appears separately.

## Scroll — resolve context
Long-form scroll may remove outer context, increase detail density, or reveal provenance/relations. Avoid continuous parallax.

“Inspect” should add information around the target instead of turning it into a generic selected card.
