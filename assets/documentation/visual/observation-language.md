# OX-DX Observation Language

**OBSERVATION IS NOT OWNERSHIP.**

Observed objects remain visually independent.

## Witness construct
Observation adds an offset **witness bracket** and **witness anchor**.

The observer does not:
- recolor the entire object;
- wrap it in a closed parent container;
- move the object under itself;
- erase native geometry.

## Canonical pattern
1. Keep the object unchanged.
2. Add one open frame offset by `3u` or `u`.
3. Align one frame break to the observed point.
4. Place a diamond anchor at the observation coordinate.
5. Optionally add a trace tail into the margin.

Multiple observations use separate anchors/brackets or shared field alignment, not nested ownership boxes.

Cyan may reinforce observation, but geometry must still communicate it in monochrome.
