# OX-DX Originality Audit

No honest design process can guarantee that a visual idea has never existed anywhere.

The correct claim is:

> **Designed as an original OX-DX visual language and intentionally separated from identified common design patterns.**

## Original visual principles

- Interrupted Evidence Field
- stable witness anchors
- measured breaks
- persistence rails
- provenance tails
- void slots
- deterministic disturbance
- resolution by decomposition rather than zoom

## Unique geometry
The supporting grammar combines opposed open frames inherited from the master mark, off-axis diamond witnesses, unequal interruption positions, relation rails whose persistence changes rather than depending on arrowheads, and nested structures that deliberately avoid generic concentric repetition.

## Unique proportion logic
The new supporting system uses 7 / 21 / 49 fields with 3 px optical offsets instead of the previous generic 8 px supporting grid. This is simple, reproducible, and linked to OX-DX's established 7 × 7 conceptual scale without mapping visual cells to ontology levels.

## Unique resolution behavior
`FIELD → RIFT → TRACE → PULSE → GRAIN`

The anchor/axis survives while enclosure and continuity change. Resolution is not zoom.

## Unique graph grammar
Relations are persistence rails. Direction is expressed through persistence, asymmetry, and endpoint behavior before arrowheads. Observed objects remain independent from witness geometry.

## Unique texture logic
Texture is deterministic loss:
- trace erosion;
- signal loss;
- compression scar;
- scan break;
- boundary wear.

No default random paper grain, fake VHS, or decorative dust.

## Unique negative-space logic
The **void slot** is measured empty space that can communicate unresolved scope or missing continuity. Empty space is notation.

## Unique motion behavior
Motion changes continuity, density, and witness state while preserving one invariant.

## Rejected design clichés
Rejected as defaults:
- Vercel-like black minimal SaaS composition;
- Linear-like soft-gradient product polish;
- Apple-like product minimalism;
- OpenAI/Anthropic-like editorial AI abstraction;
- GitHub-like repository UI grammar;
- neon cyberpunk grids;
- glowing node networks;
- circuit boards;
- hexagon systems;
- isometric cubes;
- generic Islamic tessellation as decoration;
- generic brutalist boxes;
- terminal-green hacker screens;
- Web3 orbit/network motifs;
- AI brains / neural heads;
- gradient spheres;
- glassmorphism;
- random equations or coordinates;
- random scratches / fake VHS.

## Final assessment
The system is grounded in existing OX-DX concepts and approved geometry while introducing distinct construction, spacing, interruption, provenance, graph, texture, negative-space, and motion rules.

Originality is pursued through rules, not novelty effects.
