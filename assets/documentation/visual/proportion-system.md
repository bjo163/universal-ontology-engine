# OX-DX Proportion System

The supporting visual system uses a proprietary but simple field.

`u = 7 px`

`μ = 3 px` — optical correction / trace offset.

`3u = 21 px` — observation offset / meso spacing.

`7u = 49 px` — macro field module.

This is inspired by OX-DX's existing 7 × 7 conceptual scale without mapping layout cells to ontology levels. The master logo keeps its approved geometry and is exempt from retrofitting.

## Spacing
Preferred set: `3, 7, 14, 21, 35, 49, 98 px`.

## Strokes at 196 px artboard
- primary structure: 7 px
- secondary relation: 3 px
- micro annotation: 1 px

## Node sizes
- micro grain: 7 px
- standard witness diamond: 14 px
- major anchor: 21 px

## Break widths
- local: 7 px
- relational: 14 px
- unresolved: 21 px or greater

## Corners
Square/miter by default; optional 7 px diagonal cut when functional.

## Layout ratio
Prefer asymmetric 3:4 distribution within seven logical lanes. Do not turn this into a generic 12-column system.
