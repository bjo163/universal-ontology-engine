# OX-DX Provenance Language

Provenance answers **where evidence was seen**. It does not redefine identity.

## Provenance Tail
A thin secondary rail begins at the stable object/anchor and extends toward a source margin.

Properties:
- 3 px or 1 px stroke;
- offset by `μ`;
- deterministic dropout allowed;
- ends in a source notch, not an arrowhead.

## Origin Notch
A short perpendicular cut marks composition origin, not causation.

## Source context
Source identifiers, timestamps, lines, columns, or evidence labels appear only when the underlying data exists. Never invent coordinates, timestamps, filenames, or measurements.

## Identity invariant
The main object geometry remains stable if provenance changes.

## Multiple sources
Use distinct tails with different offsets/persistence. Do not merge sources into one thick line.
