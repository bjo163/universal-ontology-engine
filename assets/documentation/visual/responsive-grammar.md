# OX-DX Responsive Grammar

Responsive design is resolution change, not desktop shrinkage.

```text
MORE SPACE → MORE CONTEXT
LESS SPACE → MORE RESOLUTION
```

## Compact: < 420 px
Preserve primary anchor, object, essential relation, and one witness cue. Remove outer context, trace labels, paired rails when one is enough, and secondary texture.

## Medium: 420–839 px
Use 3–5 logical lanes, one movable void slot, compact provenance, and limited context frames.

## Wide: 840–1259 px
Use the full seven-lane field where useful. Allow paired rails, marginal notation, and controlled disturbance.

## Large: 1260–1679 px
Add context rather than only larger type. Reveal secondary relations and provenance.

## Ultra: ≥ 1680 px
Maintain readable line lengths. Use surplus space for context/comparison/evidence annotation rather than giant typography alone.

When reducing space, delete low-priority context before shrinking critical geometry below legibility.
