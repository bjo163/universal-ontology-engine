# OX-DX Texture System

**CLEAN STRUCTURE. DISTURBED SURFACE.**

Grunge is deterministic evidence loss, not random dirt.

## Texture vocabulary

### Trace Erosion
A thin line loses measured segments as it moves away from an anchor.

### Signal Loss
Parallel rails drop out at different deterministic positions.

### Compression Scar
Short segments collapse toward one boundary and leave a hard gap.

### Scan Break
One narrow band offsets or deletes geometry across a field.

### Boundary Wear
A frame edge loses persistence near a break while corners remain precise.

## Rules
- never texture the master logo;
- never damage critical text;
- no default paper-grain, VHS, dust, or random scratch overlays;
- texture should be reproducible from fixed geometry;
- one primary disturbance class per composition.

Intensity:
- 0 = clean
- 1 = trace-level
- 2 = editorial
- 3 = poster/release maximum

Critical diagrams should normally use 0–1.
