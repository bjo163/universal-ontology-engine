# OX-DX Audio Assets — SPEC_ONLY v1.0

**STATUS: SPEC_ONLY**

No WAV/OGG/MP3 files are committed in this sensory-system task.

Reason: no dedicated sound-generation tool is available in this task environment. The repository therefore contains production-ready specifications, naming, timing, and synthesis recipes only.

Never rename a spec file to an audio extension.

## Future structure

- `sonic-logo/` — master sonic signature
- `ui/` — inspect/observe/focus/select/open/close family
- `system/` — discover/trace/connect/resolve/verify family
- `ambient/` — optional ambient field
- `transitions/` — major context transitions
- `alerts/` — warning/error family
- `source/` — synthesis recipes and timing sheet

## Future naming

`ox-dx-sfx-{event}-v{version}.wav`

`ox-dx-sonic-{name}-v{version}.wav`

Master = WAV.

Distribution = OGG/MP3 where appropriate.

Do not use `final`, `latest`, `new`, `newest`, or `test2`.
