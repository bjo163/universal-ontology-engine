# OX-DX Alert SFX Family v1 — SPEC_ONLY

Events:
- WARNING
- ERROR

## WARNING

196 ms restrained interrupted Witness.

Meaning: attention required.

No siren.

## ERROR

196–294 ms local broken transient + short low resonance.

Meaning: operation failed or evidence is malformed/unavailable at a known scope.

No screen-wide panic cue.

## Rule

Unknown is not an alert.

Unverified is not automatically an alert.

Critical meaning remains textual/visual if audio is disabled.
