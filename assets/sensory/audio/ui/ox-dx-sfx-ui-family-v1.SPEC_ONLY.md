# OX-DX UI SFX Family v1 — SPEC_ONLY

Events:
- INSPECT
- OBSERVE
- SELECT
- FOCUS
- OPEN
- CLOSE

## Shared DNA

**Witness**

A dry, precise textural transient with minimal resonant tail.

## Default behavior

- FOCUS: silent
- SELECT: optional 98 ms micro grain
- INSPECT: 196 ms witness
- OBSERVE: 196 ms softer witness + breath
- OPEN/CLOSE: optional 98 ms dry witness variants

## Production rule

Do not play a sound for every hover or focus transition.

Rate-limit repeated interaction audio.
